- 행 수: 200명, 카테고리 10개, 플랫폼 2개. 중복 ID·필수 숫자 오류 없음.
- 견적 미확인: 27명, 평점 공란: 27명. 원본의 동일한 27명에 해당한다.
- 유이력 평균 예산: 210,000~6,790,000원.
- 누적 예산과 평균 예산×건수의 불일치: 173/173명. 원인을 단정하거나 원본을 수정하지 않는다.

## 필드 해석

| 원본 필드 | 사용 | 해석 한계 |
|---|---|---|
| creator_id / creator_name | 식별·동점·표시 | 실존 채널로 연결하지 않음 |
| category / platform | 조건·참조 집단 | 세부 콘텐츠와 오디언스 정보 없음 |
| followers | 규모 필터·표시 | 참여·구매를 증명하지 않음 |
| avg_view_count | 상대 점수·표시 | 집계 기간·광고 전용 조회수 아님 |
| engagement_rate | 상대 점수·표시 | 정의·분모·기간 미제공 |
| total_campaign_count | 체감 가산·표시 | 성공 건수나 평점 표본 수 아님 |
| total_campaign_budget_krw | 감사에만 사용 | 평균 필드와 불일치 원인 미상 |
| avg_campaign_budget_krw | 참고 예산 필터·표시 | 현재 단가·세금·권리 범위 미확인 |
| advertiser_rating | 1~5 관측 점수·표시 | 공란은 미평가, 표본 수 미상 |

## 정규화·오류 처리

원본을 수정하지 않고 메모리에서 숫자·null로 변환한다. 잘못된 CSV·중복 ID·필수 결측·범위 밖 숫자는 명시적 오류로 중단한다. 잘못된 행을 조용히 삭제하지 않는다. 모든 행에 발생하는 예산 산술 불일치는 알려진 한계로 보존한다.
