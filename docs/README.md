## 설계 과정의 기록

나머지 리뷰·결정·벤치마크 적용 문서는 작성 당시의 제안과 수정 이력입니다. 이후 사용자 피드백으로 취소·변경된 화면과 미완료 계획도 포함합니다. **현재 기능 완료 여부나 정책의 기준으로 사용하지 않습니다.** 특히 단일 화면 온보딩은 현재 3단계 온보딩으로 대체했습니다. 과거 기록은 실제 비판·수정 과정을 보존하기 위해 남겼으며, 현행 요구사항과 검증은 위 문서를 우선합니다.

실험의 JSON은 Markdown의 수치를 재현하기 위한 상세 결과입니다. 더미 데이터에 대한 합성 조건이며 실제 시장·사용자 표본이 아닙니다.
