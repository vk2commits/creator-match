# 경쟁사 심층 분석 — 브랜드 마케터의 선정 판단을 돕는 방법

확인일: **2026-09-22** · 대상: 피처링, TAGby, REVU, Modash, HypeAuditor, CreatorIQ · 대체재: 직접 SNS 탐색 + 스프레드시트.

## 먼저 알아야 할 결론

**AI 검색·추천·성과 리포트 자체는 차별점이 아니다.** 이미 여러 경쟁사가 제공한다고 설명한다. 이번 과제에서 설득해야 할 것은 ‘작은 데이터셋에서도 어떤 판단을 할 수 있고, 무엇은 아직 판단할 수 없는가’와 ‘그 판단이 마케터의 다음 행동으로 이어지는가’다.

- **피처링**에서 배울 것: 채널 전체 지표와 실제 광고 콘텐츠의 반응을 구분하고, 리스트를 운영·보고로 연결하기.
- **TAGby**에서 배울 것: 선정 이후의 채팅·검수·사용권·리워드까지 협업 조건을 구체화하기.
- **REVU**에서 배울 것: 제품, 매장, 섭외처럼 사용자의 문제와 운영 방식에서 시작하기.
- **Modash**에서 배울 것: 원하는 콘텐츠를 말로 찾고, 시청자와 협업 이력을 검토한 뒤 관계 상태를 관리하기.
- **HypeAuditor**에서 배울 것: 크리에이터 본인의 특성과 그 크리에이터를 보는 사람의 특성을 분리하기.
- **CreatorIQ**에서 배울 것: 콘텐츠를 먼저 보고, AI 판단을 근거와 검토할 위치까지 연결하기.

위 내용은 아래 공식 자료를 비교한 **제품 설계 해석**이다. 서비스의 시장 우열이나 실제 추천 정확도를 검증한 결과는 아니다.

## 조사 범위와 신뢰 수준

이번 조사는 공식 제품 설명, 가격 페이지, 사용 도움말 **21개를 핵심 근거**, 사용 가이드·자동화 소개 **2개를 보조 자료**로 확인했다. 로그인 후 유료 기능 전체, 실제 캠페인 집행, 영업 상담, 사용자 인터뷰는 수행하지 않았다. 실제 화면처럼 보이는 공식 홍보 이미지도 직접 조작한 제품으로 간주하지 않았다.

| 표시 | 의미 | 해석 방법 |
|---|---|---|
| 제품 설명 | 공식 제품·가격 페이지가 제공한다고 설명 | 제공 범위의 근거. 품질·정확도는 별도 검증 필요 |
| 도움말 확인 | 사용 절차·정의·제약이 구체적으로 적힘 | 기능 동작과 제한을 판단하는 근거 |
| 미확인 | 검토한 공개 자료에서 확인되지 않음 | ‘없음’으로 표기하지 않음 |
| 우리의 해석 | 근거를 이번 과제에 적용한 판단 | 사용자 테스트로 확인할 가설 |

**비교 상황:** 브랜드 실무 마케터가 신제품 립틴트를 소개할 크리에이터 2~3명을 골라 팀에 설명하고 견적을 문의한다. 타깃은 ‘출근 준비 시간을 줄이고 싶은 직장인’, 1명당 참고 예산은 200만 원. 동일 브리프를 경쟁사에 실제 입력해 결과를 비교한 실험은 아니다. 아래는 이 업무를 각 제품이 어떻게 지원하는지에 대한 문서 기반 비교다.

## 1. 여섯 서비스의 주된 강점

| 서비스 | 특히 해결하는 업무 | 핵심 판단 재료 | 다음 업무로 연결 |
|---|---|---|---|
| 피처링 | 국내 브랜드·대행사의 후보 조사와 보고 | 콘텐츠·오디언스 필터, 광고 콘텐츠 반응 | 그룹·캠페인 저장 → 성과 리포트 |
| TAGby | 체험단 모집과 직접 운영 | 캠페인 조건, 참여 후보, 운영 통계 | 선정 → 채팅·검수·리워드 |
| REVU | 모집·섭외·운영 대행 | 제품·목표·예산, 콘텐츠 톤, 협업 기록 | 제안 → 운영 → 결과 보고 |
| Modash | 글로벌 크리에이터 탐색과 관계 관리 | 자연어·이미지 검색, 오디언스, 브랜드 협업 | 리스트 → 연락 → 추적·매출 연결 |
| HypeAuditor | 타깃 일치와 오디언스 품질 검토 | Audience Fit, 브랜드 친화도, AQS | 후보 비교 → 네트워크·캠페인 |
| CreatorIQ | 다수 브랜드·시장의 프로그램 관리 | 콘텐츠 맥락, 타깃, 브랜드 위험 | 평가 → 실행 → 맞춤 보고·조직 관리 |

각 행의 근거는 아래 서비스별 절에 연결했다. ‘특히 해결하는 업무’는 공개 포지셔닝을 바탕으로 한 분석이며 실제 고객 전체를 단정하지 않는다.

## 2. 피처링 — 광고 콘텐츠를 따로 보며 탐색과 운영을 연결

**공식 설명에서 확인한 흐름:** 브랜드·주제 키워드 → 콘텐츠·오디언스 조건으로 좁히기 → 핵심 지표 비교 → 그룹 또는 캠페인에 저장. 인스타그램·유튜브 외에도 틱톡·엑스·네이버 블로그를 안내한다. 포함뿐 아니라 제외 키워드로 탐색을 다듬는다. [F1 인플루언서 검색](https://featuring.co/product-search)

**강점:** 채널의 평균 반응만 보지 않고 광고 콘텐츠를 따로 분석한다. 과거 광고 게시물, 협업 브랜드, 광고 반응을 확인하고 댓글의 긍·부정과 구매 의향을 분석한다고 설명한다. 일반 콘텐츠가 잘되는 사람과 광고 콘텐츠에서도 제품 질문을 얻는 사람을 구분할 재료를 제공한다는 점이 유용하다. 댓글 구매 의향은 실제 구매 실적과 구분해야 한다. [F2 분석](https://featuring.co/product-analysis)

**선정 후:** 마케터가 사용할 반응 지표를 선택하고, 후보별 조회·반응·CPV·CPE를 비교하며 결과를 Excel/CSV로 내보내는 흐름을 설명한다. 팀에 보고할 자료를 다시 만드는 일을 줄이는 방향이다. [F3 결과 리포트](https://featuring.co/product-campaign-result-report)

**확인된 비용·제한:** 스탠다드 월 표시 42만 원, 3개월 구독 126만 원, 연간 378만 원. 최소 3개월 단위 안내가 있어 ‘월 42만 원만 내면 1개월 사용 가능’으로 읽으면 안 된다. 프리미엄과의 차이는 플랫폼·팀원·캠페인·발송·크레딧 등의 사용 범위다. 정확한 적용 금액과 세금은 결제 조건 재확인이 필요하다. [F4 가격](https://featuring.co/pricing)

**미확인:** 개인 캠페인 추천의 정확한 수식·가중치, 누락된 오디언스의 대체 처리, 댓글 분류의 한국어 정확도와 검토 표본, 실제 견적 확정 방식. 예측 기능을 소개한다는 사실만으로 예측 품질까지 확인된 것은 아니다.

**우리 과제에 적용:** 장차 광고 콘텐츠 URL·광고 여부·측정 기간을 별도 수집해야 한다. 지금 CSV의 평균 조회수를 ‘해당 캠페인에서 예상되는 광고 조회수’로 바꾸어 쓰지 않는다. 표에는 관측 수치를, 적합 분석에는 그 수치와 제품 맥락이 어떤 결정에 도움이 되는지를 쓴다.

## 3. TAGby — 발견보다 모집 이후의 협업 운영에 강한 흐름

**공식 설명에서 확인한 흐름:** 체험단 캠페인을 열어 모집 → 후보 선정 → 직접 채팅 → 검수와 데이터 확인. 방문형·배송형 등 다양한 체험 방식과 실시간 KPI 대시보드를 소개한다. 데이터 갱신 속도·모든 채널의 지표 범위를 직접 시험하지는 않았다. [T1 서비스](https://tagby.io/)

**실무적으로 좋은 지점:** 콘텐츠를 다른 광고에 쓸 계획이라면 모집 단계에서 사용권의 매체·기간을 정한다. 편집·가공은 별도 협의하고, 사용권 비용은 현금 리워드에 포함하도록 안내한다. 이는 ‘후보를 저장한 다음 무엇을 할까?’에 매우 구체적인 답이다. 협업 분쟁은 당사자 협의를 기본으로 하며 중재 요청 경로도 안내한다. 플랫폼이 모든 계약 결과를 보장하는 것은 아니다. [T1 FAQ](https://tagby.io/)

**확인된 유료 경계:** 무료로 동시 캠페인 1건 모집을 시작할 수 있지만 선정·상세 정보·캠페인 통계는 무료 표에서 제외돼 있다. 선정 1인당 5,000원 건별 결제, 라이트 월 65,000원·최대 15명 선정, 프리미엄 월 188,000원과 월 30회 제안하기가 표시된다. 이는 서비스 요금이며 제품 제공·크리에이터 리워드를 모두 포함한 확정 협업비로 해석하면 안 된다. [T2 가격](https://tagby.io/pricing)

**미확인:** 우리 브리프를 읽고 후보마다 적합 이유를 문단으로 작성하는 기능, 오디언스 추정의 구체적 방식, 추천 비중 직접 조절, 모든 요금제의 데이터 리포트 스튜디오 조건. 가격 표의 빈 칸을 기능 제공 또는 미제공으로 추정하지 않았다.

**우리 과제에 적용:** 문의 초안에서 제작물·게시일·수정 횟수·사용권·부가세를 빠뜨리지 않는 것이 화려한 AI 문구보다 실용적이다. 저장 → 비교·문의 후보 선정 → 조건 확인 → 협업 관리로 이어지는 흐름을 유지한다. 이번 과제의 기본 후보 확인을 결제로 막지는 않는다.

## 4. REVU — 사용자의 문제에서 시작하고 운영까지 맡기는 선택지

**공식 설명에서 확인한 흐름:** 비즈센터는 제품 리뷰, 지역·매장, 대행사, 맞춤 섭외, 글로벌로 사용 상황을 구분한다. AI 분석·REVU Score를 통한 광고주 직접 선정, 콘텐츠 가이드 자동 검수, 게시 후 모니터링을 소개한다. REVU Score의 구성 요소는 설명하지만 그 페이지에 재현 가능한 상세 수식은 없다. [R1 비즈센터](https://biz.revu.net/)

**강점:** 맞춤 섭외는 브랜드 브리핑에서 목표·방향·크리에이터 스타일·필수 노출 요소를 받은 다음, 브랜드 핏·반응·협업 이력으로 프로필을 제안하고 운영·결과 보고까지 이어진다. 후보 검색 화면만 제공하는 것보다 운영 인력이 부족한 마케터에게 맞는 선택이다. [R2 맞춤 섭외](https://biz.revu.net/casting)

**온보딩에서 배울 점:** 제품 소개는 판매 채널에 따라 필요한 콘텐츠 조합을 다르게 제안한다. 제품 카테고리·타깃·콘텐츠 톤·협업 이력을 매칭에 사용한다고 설명한다. 따라서 ‘뷰티인지, 예산이 얼마인지’에 더해 ‘어디로 고객을 보낼지, 무엇을 이해시켜야 하는지’가 중요하다. 공개 페이지에는 모집·발송·검수·성과 분석을 담당하는 전담 컨설턴트도 안내된다. [R3 제품 리뷰](https://biz.revu.net/product)

**확인된 접근 방식:** 검토한 섭외·제품 페이지는 상담·제안서·맞춤 견적 경로다. 누구에게나 적용되는 단일 공개 정액을 확인하지 못했다. 가격이 반드시 비싸다는 뜻은 아니다.

**미확인:** 추천 점수의 정확한 가중치·결측 처리, 셀프 서비스의 모든 화면과 계정별 사용 가능 범위, 견적 산정표, 예측 성과의 오차. 과거 조사에서 법인 소개만 보고 제품을 충분히 파악하지 못했던 공백을 이번에 비즈센터의 실제 상품 설명으로 보완했다.

**우리 과제에 적용:** 온보딩 질문은 결과를 바꾸는 질문이어야 한다. 제품·목표·타깃·고객의 선택 이유는 분석 문단에 사용한다. 판매 채널·희망 형식·게시일·사용권은 문의 전에 구체화하되 첫 진입에서 전부 필수로 묻지는 않는다.

## 5. Modash — 콘텐츠 탐색에서 관계·성과 관리까지 이어지는 작업실

**탐색의 강점:** 자연어로 원하는 크리에이터를 설명하거나 이미지를 넣고, 소개글·캡션·비주얼을 바탕으로 탐색한다고 설명한다. 이후 실제 오디언스 구성, 가짜 팔로워 신호, 브랜드 협업 타임라인을 검토한다. 닮은 채널, 브랜드를 이미 팔로우하는 크리에이터와 고객도 찾는다. ‘카테고리=적합’에서 한 단계 더 나아가는 입력 방식이다. [M1 Discovery](https://www.modash.io/features/influencer-discovery)

**저장 뒤의 흐름:** 리스트에 관계 상태를 붙이고, 검토 중·연락함·진행 중·종료·제외 등으로 관리한다. 사용자 정의 상태·필터·일괄 변경도 도움말에 있다. **공식적으로 확인된 제약은 상태 변경 이력 미제공, 상태 수동 변경, Manage 상태와 Track 캠페인 상태의 독립 관리**다. 이 경우 팀이 왜 보류했는지 메모를 남길 필요가 있다. [M2 상태 도움말](https://help.modash.io/en/articles/13715187-managing-creator-relationships-and-statuses)

## 9. 사용자가 적합 분석에서 실제로 얻어야 할 답

유익함의 기준은 정보량이 아니라 **선정·보류·문의 중 하나의 행동이 더 쉬워지는가**다. 다음은 합의된 브랜드 마케터 페르소나에 대한 설계 가설이며 실제 인터뷰 결과가 아니다.

| 사용자의 질문 | 필요한 분석 | 현재 제공할 수 있는 답 | 앞으로 필요한 데이터 |
|---|---|---|---|
| 왜 우리 제품을 이 사람에게 맡기나? | 분야와 제품 사용 장면의 연결 | 분야·플랫폼 + 브리프에 따른 콘텐츠 제안 | 최근 게시물·광고 사례·톤·제작 포맷 |
| 우리 고객이 왜 관심을 갖나? | 고객의 고민과 메시지 연결 | 사용자가 적은 고객·선택 이유를 반영 | 실제 고객 조사, 게시물의 제품 질문 |
| 그 고객이 이 채널을 실제로 보나? | 오디언스 겹침과 자료 신선도 | 채널 인사이트 확인 요청 | 기간이 있는 연령·지역·관심사·표본 |
| 돈을 쓸 만한 후보인가? | 강점·예산 여유·대안의 차이 | 관측 지표, 과거 비용, 동일 조건 후보 | 현재 견적·제작 수량·사용권·광고별 성과 |
| 무엇을 제안하고 확인해야 하나? | 구체적인 제작 방향과 위험 | 시작 장면·제품 설명·CTA, 협의 사항 | 제작 가능 형식·일정·수정 범위 |
| 함께 일한 후 무엇을 배울 수 있나? | 목표별 결과와 다음 결정 | 입력한 실제 비용·반응·구매 기록 | 측정 기간·출처·귀속 기준·재협업 사유 |

**첫 문단의 순서:** 크리에이터 특성 → 캠페인 제품과 타깃의 필요 → 이 분야에서 설득력 있는 사용 장면 → 관측 근거 또는 주의점 → 선정 전 확인할 한 가지. 조회수·참여율·점수 기여도는 이미 화면에 있으므로 모두 반복하지 않는다.

**뷰티와 패션을 다르게 보는 예:** 같은 립틴트라도 뷰티 분야에서는 발색·사용감 비교가 제품 선택 질문에 직접 답한다. 패션 분야에서는 옷차림에 립 컬러를 더하는 장면으로 제품의 쓰임을 제안할 수 있다. 이것은 해당 인물이 그런 영상을 올렸다는 관측이 아니다. 제품 소개 방향에 대한 가설이다.

**부적합 가능성도 답해야 한다:** 예산을 초과하면 비용 조율을, 이력이 없으면 견적과 작은 제작 범위를, 관련성이 낮은 분야라면 제품을 연결할 실제 사용 상황의 확인을 앞세운다. 모든 후보를 무조건 칭찬하면 분석의 의미가 없다.

## 11. 추천 로직과 AI 설명을 구분하는 기획

**추천 순위:** 원본의 예산·분야·팔로워 조건 → 미확인 비용 분리 → 사용자가 정한 비중과 비교 집단으로 정렬. 수식은 재현 가능하게 유지한다.

**적합 분석:** 입력한 제품·목표·타깃의 필요와 후보 분야·관측 지표를 연결한다. 이야기를 잘 썼다는 이유로 후보 점수나 자격 조건을 변경하지 않는다. ‘높은 점수=타깃이 실제로 많음=높은 매출’이라는 등식도 만들지 않는다.

현재 앱의 분석은 로컬 규칙으로 구성한 인터랙션이다. 실제 언어 모델·SNS 오디언스·게시물 수집은 연결하지 않았다. 향후 모델을 연결한다면 각 주장에 자료 ID·관측 기간을 붙이고, **관측 사실 / 제작 제안 / 추가 확인**을 구분해 출력하도록 설계한다. 누락된 자료는 추론으로 채우지 않는다. 이는 UI를 구현했다는 사실과 실제 AI 분석 능력을 혼동하지 않기 위한 제출 문서의 설명이다.

**직접 비중 조절의 역할:** 마케터가 조회·참여·이력 중 우선순위를 바꾸는 기능이다. 실제 오디언스나 제품 콘텐츠를 새로 알아내는 기능이 아니다. 경쟁사의 슬라이더 유무와 무관하게, 기본 프리셋으로 시작하고 필요한 사용자만 펼쳐 조절하는 현재 방향이 적절하다는 판단이다. 실제 이해도는 사용자 확인이 남아 있다.

## 12. 차별화와 남은 검증

우리 결과물은 경쟁사의 데이터 규모·자동 수집·메일 전송·매출 귀속·실제 AI 검색과 경쟁할 수준이 아니다. 이번 과제에서 보여줄 차이는 다음과 같다.

1. 어떤 입력이 자격 조건이고 어떤 값이 순위를 바꾸는지 명확하다.
2. 신규 후보의 0원·평점 공란을 결함 없는 값처럼 포장하지 않는다.
3. 선정 이유를 관측 근거와 브리프 연결로 설명하고, 판단을 바꿀 확인 사항을 함께 준다.
4. 추천 수식·UI·문서·검증 기록이 같은 정책을 가리킨다.
5. AI 초안의 과장·일반론을 사용자의 피드백에 따라 수정한 과정을 실제로 기록한다.

**다음 사용자 검토에서 확인할 질문:** 두 후보의 분석을 읽고 ‘어느 후보에게 어떤 콘텐츠를 제안할지’를 자기 말로 설명할 수 있는가? 타깃을 바꿨을 때 설명도 달라지는가? 실제 시청자에 대해 확인된 것과 확인할 것을 구분하는가? 저장→문의로 막힘 없이 이동하는가? ‘이유가 여전히 비슷하다’면 문장을 늘리기보다 어떤 추가 자료가 필요한지 밝혀야 한다.

경쟁사에 추가 확인할 우선 질문: 국내 대상 채널 20개를 같은 브리프로 검토할 수 있는지, 오디언스 추정·누락·갱신 정책, 결과별 근거 확인 방식, 사용권 포함 견적 처리, 실제 캠페인 귀속 방식. 가입·결제·자료 전달·영업 문의는 이번 조사에서 실행하지 않았다.
