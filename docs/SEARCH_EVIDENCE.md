# 벤치마크 3차 적용 — 검색 결과와 자료 범위

2026-09-22. Modash M-01의 편집 가능한 조건, HypeAuditor H-03의 자료 부족 구분, CreatorIQ C-01의 콘텐츠 근거 연결을 현재 데이터에 적용했다. 기존 공식 자료와 적용 계획을 재사용했으며 이번 차수에 경쟁사 계정이나 새로운 시장 자료를 조사하지 않았다.

## 문제와 결정

기존 검색은 자료가 없는 후보와 자료에서 단어를 찾지 못한 후보를 모두 숨겼다. 추가 콘텐츠 예시가 200명 중 5명에게만 있으므로 검색 누락을 부적합으로 해석할 위험이 있었다. 상단 숫자도 채널 필터 적용 전 인원이었다.

검색은 **기본 조건 → 채널 → 자료 범위 안의 키워드 판단**이다. 원본 예산·분야·규모를 몰래 완화하지 않으며 추천 수식과 가중치를 변경하지 않는다.

| 상태 | 판단 | 화면과 다음 행동 |
|---|---|---|
| 키워드 확인 | 선택한 포함 방식 충족, 등록 범위에서 제외 키워드 발견 없음 | 원래 추천 순서 유지. 키워드에서 콘텐츠·소개·채널 근거 열기 |
| 자료 확인 필요 | 콘텐츠 자료가 없어 포함 조건 또는 제외 표현을 확인할 수 없음 | 별도 목록에 유지. 저장·분석·문의·자료 등록 가능 |
| 검색에서 제외 | 제외 키워드를 발견했거나, 등록 자료에서 필요한 포함 조건을 찾지 못함 | 접힌 목록에서 서로 다른 이유와 자료 열기 |
| 다른 채널 | 선택한 플랫폼과 다름 | 현재 채널의 인원수에서 제외. 모든 채널로 명시적 해제 가능 |

‘등록 자료에서 미확인’은 그 크리에이터가 해당 콘텐츠를 만들지 않는다는 결론이 아니다. 제외 키워드가 없다는 것도 채널 전체의 검증을 의미하지 않는다. 실제 타깃 오디언스·성과·브랜드 안전성을 검색어로 확정하지 않는다.

## 입력과 숫자의 정책

- 포함 방식은 기본 ‘하나 이상 포함’이며 편집에서 ‘모두 포함’을 선택할 수 있다. 제외 키워드가 발견되면 포함 일치보다 우선한다. 동일 키워드를 양쪽에 넣으면 제외된다.
- 이름·플랫폼·분야는 CSV에서 검색할 수 있다. 추가 자료가 없어도 이 필드의 실제 일치는 근거가 된다. 다만 콘텐츠 제외 표현까지 확인해야 하면 별도의 자료가 필요하다.
- 콘텐츠는 제목·캡션·브랜드·표현 태그, 소개는 소개글·스타일·키워드에서 확인한다. 댓글은 이 키워드 검색에 포함하지 않는다. 공백·해시태그 접두사·영문 대소문자·전각 문자 표기를 정규화한다.
- 검색 문장은 편집 가능한 초안으로만 사용한다. 사용자가 적용하기 전 결과는 바뀌지 않으며 취소는 기존 검색을 유지한다. 제외만 요청한 문장을 포함 키워드로 넣지 않는다. 제외한 단어는 추천 키워드에서 뺀다.
- 상위 **예산 내 후보 / 견적 필요** 탭 숫자는 기본 조건과 선택 채널을 충족하는 모집단이다. 각 탭에서 **확인 + 자료 필요 + 검색 제외 = 해당 탭 인원**이다. 현재 목록에 표시할 인원은 따로 안내한다.
- 키워드 해제는 예산·분야·규모·채널·현재 예산 탭·저장 후보를 유지한다. 채널 해제도 키워드를 유지한다. 조건 대안의 인원은 현재 검색까지 적용한 확인/자료 필요 숫자로 표시한다.
- 추천순이나 다른 정렬은 각 확인 상태 안에서 그대로 유지한다. 자료 유무를 추천 점수에 가산하지 않는다. 저장 목록은 검색 조건 때문에 숨기지 않는다.
- 자료 등록 후 후보를 다시 분류하고 검색 근거를 갱신한다. 사용자 등록 자료는 다른 캠페인에서도 참조하는 채널 공통 자료다. 미입력 조회수를 0으로 바꾸거나 원본에 합치지 않는다.

## 목록과 작은 UX

같은 사진 두 장을 없애고 검색 근거가 있는 게시물 한 개를 제목·형식·날짜와 함께 보여준다. 검색이 없으면 가장 최근 자료를 사용한다. 썸네일이 없으면 플랫폼 아이콘과 제목을 쓴다. 자료가 없을 때 큰 등록 상자를 반복하지 않고 작은 ‘자료 확인’으로 연결한다.

카테고리·플랫폼을 설명 문장으로 다시 반복하지 않는다. 협업 건수와 평점을 나누어 읽고 작은 분석·저장 버튼은 유지한다. 검색창의 영어 AI Search 제목을 과업 중심 한국어 질문으로 바꾸고 참고 이미지를 한 줄 안에 배치했다.

하단의 큰 저장 바가 짧은 결과 목록을 가려 제거했다. 저장 직후 알림의 ‘저장한 후보 보기’와 항상 있는 왼쪽 메뉴로 이동한다. 저장이 비교를 강제하지 않으며 후보 한 명에게 바로 문의할 수 있다.

## 실행한 검증

**15개 파일 200개 테스트 통과**, 새 검색 정책 15개 포함. 최신 UI 변경 후 타입·빌드도 통과했다. 원본/앱 CSV 해시 동일. 데스크톱 전용 별도 `?demo` 탭에서 확인했다.

| 과업 | 관찰 결과 |
|---|---|
| 기본 뷰티·패션 / 200만원 / 1만–10만 | 예산 내21명, 견적 필요3명 |
| 미니멀 포함·화려한 제외 | 예산 내: 확인2 / 자료 필요17 / 제외2. 제외 이유는 화려한 발견과 미니멀 미확인으로 구분 |
| 검색 근거 열기 | 서연리뷰66의 미니멀 → 해당 재킷 콘텐츠·표현 태그 |
| 자료 필요 목록 | 17명 유지, 12명→전체 더 보기, 저장 가능 |
| 견적 필요 탭 | 확인1 / 자료 필요2. 키워드 해제 후 같은 탭에서3명 표시 |
| 직접 입력·취소·모두 포함 | Enter 없이 적용해도 입력 반영. 취소는 이전 OR 유지. 모두 포함으로 미니멀·출근룩 검색 시 확인1명, 새로고침 후 방식·후보 보존 |
| 인스타그램 필터 | 예산 내11명·견적 필요2명. 키워드 해제 시11명, 모든 채널 해제 시21/3 복원 |
| 자료 연결 | 지우라이프13에 별도 검증 자료 등록 후 확인2→3, 자료 필요17→16. 해당 게시물 근거로 이동 |
| 저장 다음 행동 | 저장 알림에서 저장 목록으로 이동, 기존 두 후보 유지 |

자료 연결 테스트의 게시물은 AI가 기능 검증용으로 입력한 예시이고 실제 SNS 관측이 아니다. 200개 검사는 사람의 이해도·추천 정확도·실제 AI 품질을 증명하지 않는다. 한글 조합 중 Enter 방지는 코드에 유지했으나 실제 IME 조합의 종단 간 조작은 이번에 수행하지 않았다.

## 남은 범위

조건 대안의 검색 인원은 코드 계산을 일치시켰으나, 모든 대안 조합을 실제 브라우저로 반복하지 않았다. 캠페인별 서로 다른 성과의 저장·전환, 최신 전체 기능의 새 환경 재현, 파일 다운로드, 실제 모델 응답, 사용자 최종 과업 검토가 남아 있다. 공개·외부 발송·모바일 검증은 수행하지 않았다.
