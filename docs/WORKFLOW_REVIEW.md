# 5차 UX 검토: 브리프에서 문의·성과까지

2026-09-21. 사용자 요청으로 브랜드 실무 마케터의 흐름을 확장했다. 추천의 근거와 문서화가 과제의 핵심이며, 추가 기능은 그 판단을 업무에 연결하는 범위로 제한한다. 경쟁 서비스의 공개 공식 문서와 실제 제품 사용을 구분한다. 실제 마케터 인터뷰는 수행하지 않았다.

## 이전 흐름의 부족함과 채택한 결정

| 관찰 | 근거 | 제품에서 달라지는 것 | 검증 |
|---|---|---|---|

## 온보딩에서 무엇을 묻고 왜 묻는가

1. **캠페인명·제품과 메시지·목표**: 진행 중인 업무를 식별하고 문의 문안·성과 요약에 재사용한다. 목표는 제품 알리기/관심·반응/구매 연결. 각각 조회수 우선/참여율 우선/균등을 시작점으로 제안하되 마지막 단계에서 사용자가 수정한다. 구매 목표를 전환 예측으로 오인하지 않도록 해당 데이터가 없음을 안내한다.
2. **1명당 예산·분야·팔로워 규모**: 제공 CSV로 판정 가능한 후보 자격이다. 원문의 필수 입력도 충족한다.
3. **추천 기준·직접 비중**: 사용자 판단을 순위에 반영한다. 숨겨진 정답 가중치가 아니라 명시적으로 조정 가능한 가정이다.

문의 준비에서 묻는 정보: 직접 확인한 채널·이메일, 제작 형식·수량, 게시 일정, 사용권, 합의 비용. 집행 결과에서는 실제 집행비·콘텐츠 링크·측정일·출처·구매 집계 기준을 묻는다. 온보딩에서 이 모든 입력을 강요하지 않는다.

현재 묻지 않는 정보: 회사 규모·직급·팀원 초대는 이번 탐색에 필요하지 않다. 오디언스 연령·성별·브랜드 안전성은 CSV에 없어 추천 조건인 것처럼 받지 않는다. 다만 캠페인 브리프에 작성할 수 있으며 충족을 판정하지 않는다. 선호 플랫폼 필터는 실제 마케터 테스트에서 추가 우선순위를 확인할 다음 후보 기능이다. 이번에는 플랫폼 아이콘·상세·동일 플랫폼 내 정규화를 제공한다.

## 문의와 성과의 동작 경계

- 이메일은 직접 입력한 주소로 사용자의 이메일 앱에 초안을 연다. 자동 발송하지 않는다. 복사·초안 열기는 상태 변경의 증거가 아니다.
- 상태는 문의 준비/답변 대기/조건 협의/제작 진행/집행 완료/진행 안 함이다. 연락 이후 상태에는 실제 문의 날짜, 제작 진행·완료에는 합의 비용과 제작 범위가 필요하다.
- 합의 비용을 실제 집행비로 자동 대입하지 않는다. 비용 협의와 실제 지출의 차이를 보존한다.
- 한 크리에이터당 이번 콘텐츠의 최신 누적 결과 한 건을 기록한다. 다수 콘텐츠·복수 캠페인·시계열은 아직 지원하지 않는다.
- 기록은 로컬 브라우저 저장이다. 운영 서비스의 공동 작업·백업·접근 권한을 제공하는 것은 아니다.
- ‘예시 리포트’는 저장하지 않는 별도 데이터다. 실제 입력 합계와 섞지 않는다.

## AI의 역할과 제한

| 위치 | 입력 | 결과 | 적용 권한 |
|---|---|---|---|
| 온보딩 | 캠페인 브리프·사용자 요청 | 메시지 초안·확인 질문 | 사용자 검토 후 메시지 칸만 변경; 예산·가중치는 변경 안 함 |
| 문의 준비 | 편집 중인 문의 문안 | 다듬은 문안·확인 질문 | 검토 후 문안에 적용; 발송 안 함 |
| 성과 리포트 | 직접 기록한 수치·출처·계산값, 최대 8명 | 서술형 요약·후속 질문 | 편집·복사; 점수나 재계약 자동 결정 안 함 |

모델이 없을 때 기본 문안·직접 입력·요청문 복사로 계속 진행한다. 이것을 ‘실제 AI 생성’으로 표시하지 않는다. 키는 서버 환경변수, 호출은 명시적 버튼, 응답은 편집 가능한 초안이다. 제품 AI의 실효성과 모델 출력 품질은 연결 후 추가 평가가 필요하다.

## 카피·시각 체계

- 추상적인 ‘완료’ 대신 ‘추천 후보 보기’, ‘문의 준비로 이동’, ‘답변·견적 기록’, ‘성과 기록’으로 다음 결과를 예고한다.
- 반복 공통 체크리스트 대신 후보별 결측·초과 정보와 실제 문의 필드를 해당 시점에 배치한다.
- 주요 행동은 숲색, AI·성과는 보라, 확인 대기는 주황. 플랫폼은 아이콘, 분야는 태그로 표시한다.
- 로딩은 CSV 요청과 실제 Worker 계산에 연결한다. 임의 지연·가짜 퍼센트·AI 분석 중이라는 허위 표현을 넣지 않는다. 데이터 200명의 계산이 빨라 로딩은 짧게 보일 수 있다.

## 남은 중요한 개선 검토

1. **사람이 이해하는가**: 브랜드 마케터 3~5명의 탐색→문의→성과 과업을 관찰해야 한다. 테스트 참가자 수는 계획이며 실제 진행 인원이 아니다.
2. **직접 비중의 과신**: 사용자가 %를 예측 정확도로 오인하는지 확인한다. 어려우면 프리셋을 유지하고 상세 제어의 노출을 재검토한다.
3. **실제 AI 응답 품질**: API 연결 후 누락된 견적·지표를 만들어내는지, 수치를 그대로 유지하는지 평가한다. 현재 실제 호출 검증은 미완료다.
4. **복수 캠페인과 자동 수집**: 단일 작업실·수동 기록의 한계다. 유료 가치는 팀 권한·캠페인 이력·자동 수집·반복 보고에 두고 추천 이유 자체는 잠그지 않는다. 과금·구독 UI는 아직 만들지 않았다.
5. **제출 설득력**: 기능 수로 차별화를 주장하지 않는다. ‘필터·순위·설명·실제 결과를 구분하고, 결정과 검증의 출처를 남겼다’는 점을 사례로 설명한다. 다른 지원자 결과물을 보지 않았으므로 독점적 차별성은 주장하지 않는다.
