## 추가 설계 검토에서 발견한 문제 — 아래 개선 적용으로 해결

2026-09-21 후속 검토. 기존 54개 테스트는 통과했으나 아래 설명의 예외까지 검증한 것은 아니다.

- 비교 집단을 플랫폼 전체로 확대하는 경우에도 상세는 원래 플랫폼×규모의 중간값을 별도로 계산한다. 합성 20명의 점수 비교 집단 중간값 8,500회와 현재 화면 수식의 150회가 다른 것을 재현했다. 현재 CSV에서는 각 집단이 10명 이상이므로 이 예외가 발생하지 않는다. 실제 브라우저 재현이 아닌 소스 대조·합성 계산 검증이다.
- 원본 예산 산술 불일치 설명이 상세에서 공통으로 노출된다. 이력 없는 27명은 0=0으로 일치하므로 개별 데이터에 맞는 문구 분기가 필요하다. 현재 원본 값과 화면 소스를 대조했다.

원본·추천 정책은 변경하지 않았다. 네 우선순위 민감도, 단일 원지표 정렬 비교, 지표 제거, 최대 기여와 후보 간 차이의 분석은 [추가 진단](LOGIC_REVIEW.md)에 기록했다. 당시 진단 이후 사용자의 개선 적용 요청에 따라 아래 수정·회귀 검증을 수행했다.
