## 데스크톱에서 관찰한 핵심 경로

1. 예시 설명을 입력해 제품·타깃·200만 원·뷰티/패션·마이크로가 다음 단계에 전달됨. 세 단계 모두 왼쪽 안내·오른쪽 입력, 나노/마이크로/매크로와 숫자 구간 표시.
2. 추천 완료 후 21명·비용 미확인 3명. 조회수 우선에서 정은매거진77, 참여율 우선 적용 후 서연리뷰66. 원조회수 정렬도 별도로 작동.

4. 예산 1원 → 적격 0명·미확인 3명 → 540,000원 제안과 추가액 확인 → 적용 후 소라TV177 한 명.

6. 문의 문안·조건 기록, 같은 후보의 서로 다른 캠페인 문안·상태 전환 및 새로고침 복원.
