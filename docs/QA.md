## 추가 설계 검토에서 발견한 문제 — 아래 개선 적용으로 해결

2026-09-21 후속 검토. 기존 54개 테스트는 통과했으나 아래 설명의 예외까지 검증한 것은 아니다.

- 비교 집단을 플랫폼 전체로 확대하는 경우에도 상세는 원래 플랫폼×규모의 중간값을 별도로 계산한다. 합성 20명의 점수 비교 집단 중간값 8,500회와 현재 화면 수식의 150회가 다른 것을 재현했다. 현재 CSV에서는 각 집단이 10명 이상이므로 이 예외가 발생하지 않는다. 실제 브라우저 재현이 아닌 소스 대조·합성 계산 검증이다.

**86개 테스트·타입·프로덕션 빌드 통과.** 원본 추천 검증을 유지하고 연락 상태의 입력 조건, 성과 결측/0/달력 날짜, 출처·구매 집계 기준, 0 분모, 부분 집계의 짝, 문안·기록 복구, 예시 분리, AI 스키마·거절·미완료·입력 크기 검증을 추가했다. 실제 AI 호출 성공은 테스트하지 않았다.

데스크톱 인앱 브라우저에서 확인:
- 3단계 온보딩. 캠페인명·제품 메시지 입력→조건→기준. 조회수 우선 프리셋에서 조회수80%를 입력하면9/80/7/4, 합100. 적격21명·비용 미확인3명과 정은매거진77 첫 추천 확인.
- 협업 관리에 문의 후보1명 표시. 문안을 복사해도 문의 준비·연락 전 유지. 날짜·합의 비용·제작 범위 없이 제작 진행 저장 시 필요한 정보 안내.
- 날짜 입력이 화면에만 남고 저장 시 누락되는 경로를 발견했다. 입력 이벤트를 보강한 뒤 2026-09-21 문의·측정 날짜와 합성 수치를 저장하는 데 성공했다.
- 합성 예: 비용100000/조회10000/좋아요100/댓글20/공유10/저장20/클릭500/구매10/매출200000. 상세에서 CPV10원, CPE666.67원, CPC200원, CPA10000원, 입력매출/집행비200% 확인. 출처를 ‘검증용 합성 데이터·실제 성과 아님’으로 표시했다.
- 검증용 수치를 키보드로 비워 저장한 뒤 내 성과0명·미입력·효율 ‘—’ 확인. 별도 예시 리포트는 경고와 함께 같은 계산을 보여주며 내 기록에 저장하지 않는다.
- AI 다듬기에서 연결 필요·생성 비활성·연결 안내·요청문 복사 확인. 실제 API 연결은 대기 상태다.
- 현재 데스크톱 분할 패널에서 온보딩 가로 잘림을 수정하고 시각 확인했다. 축소된 사이드 메뉴에도 이름을 표시했다. 모바일 전용 작업·뷰포트·검증은 추가하지 않았다.

로딩은 CSV 요청과 Worker의 실제 pending 상태에 연결되어 있다. 원자료200명의 계산이 빨라 브라우저 관찰 시 바로 결과가 표시될 수 있다. 로딩을 보여주기 위한 인위적인 지연은 넣지 않았다. Worker 강제 장애의 실제 브라우저 재현은 수행하지 않았으며 오류 분기와 요청 폐기는 코드 점검 범위다.

흐름도 3개의 Mermaid 구문을 로컬 파서에서 확인했다. 최신 추천 수식·CSV는 변경하지 않았으며 원본 해시 검사는 자동 테스트에 포함된다. 별도 폴더 설치 재현은 앞선 커밋에서 수행한 기록이다. 최신 코드의 검증은 현재 작업 폴더에서 수행했으며 의존성 추가는 없다.
