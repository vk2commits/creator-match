# 벤치마크 2차 적용 — 설명 한 번, 검토 한 화면

2026-09-22. REVU R-01·02와 Modash M-03을 현재 데이터·브라우저 저장 범위에 맞게 적용했다. 경쟁사 제품을 사용한 비교 실험이나 사람 대상 사용성 검증은 아니다.

## 바꾼 이유와 화면

기존 네 단계는 문장에 이미 적은 제품·타깃·예산을 다시 여러 화면에서 확인하게 했다. 새 캠페인은 **설명 → 초안 검토** 두 단계다. 직접 입력을 선택하면 바로 검토 화면을 연다. 저장된 캠페인의 설정도 검토 화면부터 열린다.

| 위치 | 입력·행동 | 실제 사용처 |
|---|---|---|
| 시작 | 어떤 제품을 누구에게 소개할지 한 문장, 예시 넣기 또는 직접 입력 | 인식한 제품·타깃·목표·조건·표현 방향·필수 요소의 초안 |
| 검토 왼쪽 | 캠페인명·제품·목표, 선택 타깃 | 분석의 제품·사용 장면·고객 설명, 문의 |
| 검토 오른쪽 | 1명당 예산·분야·팔로워 구간 | CSV 후보 자격 판정 |
| 선택 펼침 | 표현 방식·꼭 담을 내용·고객의 선택 기준 | 적합 분석의 제작 제안·확인할 질문 |
| 추천 우선순위 | 네 프리셋·슬라이더·숫자 입력 | 적격 후보의 지표 순위 |
| 고정 하단 | 현재 기준·비중 조절 바로가기·미선택 조건·추천받기 | 조절 위치를 찾고 설정을 명시적으로 적용 |

일정·제작 수량·사용권·연락처는 문의할 때, 성과 수치와 출처는 게시 후에 받는다. 목표를 구매 연결로 선택해도 구매 확률은 계산하지 않는다.

## 입력의 확정과 보존

- 신규 예산·분야·팔로워는 빈 값으로 시작한다. 문장에 없는 필수 조건을 임의의 기본값으로 확정하지 않는다. 타깃은 비워도 진행한다.
- 목표를 읽지 못하면 ‘제품 알리기’ 시작값임을 검토 화면에 표시한다. 목표별 기준은 사용자가 아직 기준을 고르지 않았을 때만 바뀐다. 직접 프리셋·비중을 선택하면 이후 목표 변경이나 재정리로 덮어쓰지 않는다.
- ‘1명당/인당/한 명당’이 있는 금액만 예산으로 읽는다. 전체 예산을 나누지 않는다. 쉼표·만원 표현을 처리하고 0·음수·소수 원화·안전 범위 밖 금액은 검증 오류로 남긴다.
- 다시 설명을 정리해도 명시하지 않은 기존 타깃·표현·필수 요소와 직접 바꾼 캠페인명·비중은 유지한다. 자동 캠페인명은 새 제품으로 갱신할 수 있다.
- 오류에는 필드별 안내·초점을 제공한다. 설정 취소는 기존 캠페인을 바꾸지 않는다. 완료 전 폼은 화면 안에서 유지되며, 새로고침·다른 캠페인 전환까지 미완료 초안을 저장하는 기능은 없다.
- 새 캠페인은 저장한 후보·문의 없이 시작한다. 완료된 캠페인의 조건·후보·문의·상태·성과 저장은 캠페인별이고 채널 콘텐츠는 공통이다.

## 실제 확인

**14개 파일 185개 자동 테스트·타입·빌드 통과.** 기존 171개에 입력 추출·보존·검증 14개를 추가했다. 원본/앱 CSV의 SHA-256이 동일하다. 추천 수식은 바꾸지 않았다.

별도 데스크톱 `?demo` 탭에서 다음을 확인했다.

1. 짧은 제품 설명에서 없는 타깃·예산·분야·규모가 채워지지 않는다. 누락 제출은 차단되고 첫 오류로 초점이 이동한다.
2. 예시 설명의 직장인 타깃·2,000,000원·뷰티/패션·1만–10만·자연스러운 일상·필수 발색/지속력이 검토 화면에 반영된다. 수동 캠페인명은 재정리 후 유지된다.
3. 참여율 비중 40% 입력 후 40/41/11/8, 합계100. 구매 목표로 바꿔도 이 값을 유지한다. 비중 바로가기는 첫 슬라이더로 초점도 이동한다.
4. 적용 후 4.2초 조건 안내와 추천21명·비용 미확인3명을 확인했다. 로딩의 시간은 실제 검색 처리율이 아닌 기존 표현 시간이다.
5. 필수 발색·지속력이 후보 분석의 제작 제안·질문과 문의 초안에 연결된다.
6. A는 제작 진행·기존 문안, B는 문의 준비·다른 문안으로 저장했다. 전환과 새로고침 후 서로 보존된다. B 생성 직후 A의 저장 후보가 복사되지 않는 것도 확인했다. 이번 차수에 캠페인별 서로 다른 성과 수치까지 다시 입력해 검증하지는 않았다.
7. 기존 설정에서 캠페인명을 임시 변경한 뒤 취소하면 원래 이름과 저장 조건을 유지한다. 직접 입력 경로의 필수 누락도 차단된다.

개발 중 새 파일이 생기기 전에 모듈이 갱신되면서 이전·새 컴포넌트가 섞인 빈 화면을 한 번 관찰했다. 파일 구성이 완료된 후 새로고침하여 위 경로들을 확인했다. 사용자의 일반 기록은 변경하지 않았다.

## 한계와 다음 검토

문장 정리는 정해진 한국어 표현을 읽는 로컬 규칙이다. 자유 문장을 전부 이해하는 모델의 품질을 검증한 것이 아니다. 잘못 읽은 값을 수정하는 검토 단계를 유지한다. 실제 모델·파일 다운로드·최신 전체 기능의 새 환경 재현은 이전 미검증 항목으로 남는다.

다음은 키워드 검색에서 **일치 / 자료 확인 필요 / 제외 근거 있음**을 구분하는 작업이다. 그다음 목록의 중복 설명·이미지를 정리하고, 사용자가 두 후보를 비교하여 한 명의 문의 초안을 만들 수 있는지 확인한다. 모바일·공개 제출은 수행하지 않았다.
