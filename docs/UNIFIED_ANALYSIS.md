# 벤치마크 1단계 적용 — 적합 분석에서 근거와 문의까지

2026-09-22. [전체 적용 계획](BENCHMARK_APPLICATION_PLAN.md)의 첫 번째 실행 단위다. 전체 개선·사용자 검토·제출 완료를 의미하지 않는다.

## 해결한 문제

분석 모달, 콘텐츠 상세, 별도 리포트 생성에 비슷한 내용이 흩어져 있었다. 지금은 **한 후보의 분석 결과 하나**를 화면·근거 링크·문의 제안·리포트가 함께 사용한다. 마케터는 적합 문단을 읽고, 근거를 확인하고, 실제로 물을 질문을 골라 문의로 넘긴다.

## 실제 흐름

1. 목록의 작은 **적합 분석** 버튼을 누른다.
2. 캠페인·후보의 자료를 읽는 동안 로딩을 표시한다. 현재 키가 없는 환경은 빠르게 로컬 결과를 사용한다. 일부러 2.1초를 기다리는 이전 분석 지연은 제거했다.
3. 첫 문단은 **후보의 표현 → 제품·고객과 연결 → 근거 → 조율할 점**이다. 채널 원지표는 접어서 추가로 확인한다.
4. 근거를 누르면 같은 창 안의 해당 게시물 또는 광고 댓글로 이동한다. **적합 분석으로 돌아가기**로 원래 판단을 다시 읽는다.
5. 필요한 질문만 선택하고 **제안 담아 문의하기**를 누른다. 신규 문의에는 콘텐츠 제안과 선택한 질문만 들어간다. 내부 점수·평가 문단은 보내지 않는다.
6. 이미 문안을 작성했다면 **기존 문의에 제안 추가**에서 추가 내용을 먼저 확인한다. 기존 문안 뒤에 붙이며 같은 내용을 중복해서 붙이지 않는다. 제작 진행 중인 후보의 단계도 되돌리지 않는다.
7. 리포트는 화면에 표시된 최종 문단·근거·질문을 그대로 사용한다. 파일 저장 버튼과 복사 대안을 제공한다. 파일 저장 완료와 복사 완료는 다른 검증 항목이다.

## 데이터·AI 경계

- 원본 CSV 200명은 수정하지 않는다. 조건 필터와 지표 순위는 기존 순수 함수와 사용자 비중을 유지한다.
- 추가 콘텐츠 자료는 **5명에 대한 별도 편집 예시**이며 실제 SNS 수집 결과가 아니다. 생성 이미지도 실제 인물·계정 사진이 아니다. 해당 출처는 상세와 리포트에 있다.
- 자료 없는 후보의 분석은 CSV와 캠페인 입력만 사용한다. 콘텐츠 자료가 적다고 추천 점수를 낮추지 않는다. 다만 키워드 검색에서 미확인을 별도로 보여주는 정책은 아직 구현 대상이다.
- 직접 등록한 게시물·댓글은 원본 CSV와 분리한다. 한 후보의 첫 등록부터 해당 후보의 편집 예시를 대체한다. 다른 캠페인에서도 같은 채널 자료를 참조한다.
- 댓글의 긍정·중립·부정과 제품 질문·구매 의향은 별도다. 미분류 댓글은 집계 분모에서 제외하고 원문은 보존한다. 구매 의향을 실제 구매로 바꾸지 않는다.
- 선택적 모델 연결이 설정돼 있으면 검색·적합 분석에서 실제 요청을 보낸다. 키는 서버에만 둔다. **이번 환경은 미설정이며 실제 모델 응답의 품질·지연·비용은 검증하지 않았다.**
- 모델이 인용한 근거 ID가 제공 목록에 없으면 결과를 표시하지 않는다. ID의 존재 검사는 의미상 사실성을 보장하지 않는다. 모델 해석 검토는 별도로 필요하다.
- 화면·문의·내보내기에 같은 분석 결과를 사용하며 캠페인·비중·자료가 바뀌면 이전 결과를 재사용하지 않는다. 메모리 캐시는 최대 30개다.

## 실제 검증

- 자동 검사: 전체 13개 파일 171개 테스트·타입 검사·프로덕션 빌드 통과. 원본 200명·조건 경계·정렬·비중·저장·분석 근거·문의 보존·등록 자료 검사 포함.
- 원본과 앱 CSV의 SHA-256 동일: `6f139b1a8cac4a7aa0d8034bde2df16ae7c06896ee820eec16ddafbcf2738b8c`.
- 데스크톱: 민준브이로그180과 시우매거진155의 서로 다른 적합 문단·조율점 확인. 광고 댓글 근거에서 해당 콘텐츠로 이동.
- 문의: 선택 해제한 질문 제외, 선택한 질문만 전달. 직접 쓴 문안에 추가 후 기존 문안·제작 진행 상태 유지.
- 등록: 제목·게시일·캡션의 필수 표시와 누락 시 첫 필드 초점. 접두사 없는 주소의 https 보완. 빈 조회수는 미확인. 댓글 분류 뒤 추가한 문장 보존·미분류 유지. 새 자료 반영과 페이지 갱신 후 보존.
- 리포트: 화면 문단과 동일한 내용이 복사됨을 확인. 앱 안 브라우저에서는 다운로드 이벤트·저장 파일을 확인하지 못함. 다운로드 완료로 보고하지 않는다.
- 사람 대상 사용성 테스트·실제 AI 응답·외부 발송·자동 수집·모바일 검증은 수행하지 않았다.

## 다음 순서

1. **온보딩 적용:** 설명→한 화면 검토로 바꾸고 필수값·입력 보존을 확인했다. [2차 적용 기록](ONBOARDING_REVIEW.md).
2. **검색:** 키워드 일치 / 자료가 부족해 확인 필요 / 명백한 제외를 나누고 숫자·해제 동작까지 맞춘다. 지금 5명 자료의 범위로 전체 200명의 콘텐츠 일치 여부를 판정하지 않는다.
3. **목록과 상태:** 반복 태그·설명·같은 이미지 미리보기 정리. 캠페인별 후보·문의·상태는 2차에서 전환·새로고침을 확인했다. 성과 수치의 추가 검증은 남아 있다.
4. **사용자 검토:** 한 캠페인에서 두 후보의 차이를 설명하고, 한 명에게 문의 초안을 만드는 과업. 납득하지 못한 문구와 다음 행동을 찾지 못한 곳을 기록한다.
5. **제출 정합성:** 위 변경 후 원문 요구사항·문서·코드·커밋·공개 제외 자료를 다시 대조하고 사용자 확인을 받는다. GitHub 공개와 제출 메일은 아직 수행하지 않았다.

Pro는 기본 추천·근거·개별 문의를 막지 않는다. 팀 검토, 반복 캠페인 보고서, 일괄 운영의 유료 가치는 아직 검증 전 가설이다.
