# 리서치: 후보 탐색에서 설명 가능한 비교로

확인일: 2026-09-21. 공개 제품 설명·도움말·산업기관 자료를 조사했다. 유료 제품의 로그인 후 추천 동작은 직접 검증하지 않았다. 실제 광고주 인터뷰는 수행하지 않았다. 아래 사용자 상황은 제품 가설이다.

## 결론과 제품 결정

1. **탐색 다음의 판단을 돕는다.** 경쟁 서비스는 이미 검색·분석·관리를 제공한다(S04, S09, S12). 이 프로토타입은 같은 기준으로 후보의 원지표와 추천 이유를 함께 보여준다(D04).
2. **예산을 확인한 정도를 구분한다.** 가격은 플랫폼·형식·이용권한 등에도 좌우된다(S03). 과거 평균을 견적처럼 표시하지 않고 신규 후보는 별도 검토 영역으로 분리한다(D01, D02).
3. **비교 집단을 밝힌다.** 플랫폼별 참여율 정의가 다를 수 있다(S06). 제공 데이터의 정의가 없으므로 재계산하지 않고 같은 플랫폼·규모 내 상대 위치를 사용하며 한계를 설명한다(D05).
4. **추천 점수와 성과 예측을 구분한다.** 참여 지표는 사업 결과 자체가 아니다(S02, S03). 매출·전환 데이터 없이 ROAS나 성공 확률을 출력하지 않는다(D06).
5. **필수 동작을 실증한다.** 경쟁사의 독점 수식과 성과를 복제했다고 주장하지 않는다. 조건 준수, 원본 보존, 설명 일치, 순위 변화를 실제 데이터로 검증한다(D07).

## 회사와 직무 맥락

모비데이즈의 공식 서비스 페이지는 데이터 기반 기획·분석·보고와 애드테크 지원을 설명한다(S01). 이 프로젝트의 판단 근거와 재현 가능한 분석을 강조하는 배경으로만 사용한다. 회사의 내부 제품 전략 또는 채점 방식을 추론하지 않는다.

검색된 별도 PM(Partnership Management) 인턴 공고는 이번 서비스 기획자 직무의 근거에서 제외했다. 제목의 약어가 같다는 이유로 직무를 혼용하지 않았다. 약 2016년을 나타내는 파일명을 가진 오래된 회사 소개 자료도 최신 사업 근거로 사용하지 않았다.

## 사용자와 업무 흐름: 검증 전 가설

주 사용자는 사용자가 선택한 브랜드 실무 마케터다. 예산과 카테고리가 정해져 있어도 서로 다른 규모·플랫폼의 지표를 비교하기 어렵고, 집행 이력과 가격을 확인해야 한다는 가설이다. IAB의 산업 관찰은 분산된 데이터의 수동 취합 문제를 설명하지만(S03), 이 과제의 특정 사용자 문제를 인터뷰로 입증한 것은 아니다.

업무 흐름: 조건 설정 → 후보 탐색 → 원지표와 추천 이유 비교 → 미확인 정보 확인 → 견적·콘텐츠 협의 → 최종 선정. 5차 구현은 후보 검토 이후의 문의 문안·수동 협업 상태·성과 기록까지 연결한다. 실제 발송·자동 수집·계약은 범위 밖이다.

향후 사용자 검증: 담당자에게 기존 방식과 프로토타입으로 같은 브리프의 후보를 검토하게 하고, 첫 유효 후보 발견 시간·조건 해석 오류·추천 이유 설명 가능 여부를 관찰한다. 표본 수와 개선 목표는 연구 설계 후 정하며 지금은 개선율을 주장하지 않는다.

### 직접 화면 확인

Computer 도구로 피처링의 공개 영향력 분석 페이지를 열었다. 영문 페이지로 이동했고, 분석 지표·광고 콘텐츠·브랜드 이력 섹션과 영업 문의 경로를 확인했다. 이 관찰은 공개 소개 화면에 한정되며 실제 추천 화면을 사용한 것으로 기록하지 않는다.

### 미확인 항목

경쟁사별 후보 없음 처리, 결측치 정책, 가중치, 동점 규칙, 실제 견적 제시 여부는 대부분 공개 문서에서 확인되지 않는다. 이 빈칸은 경쟁사의 약점이라는 주장의 근거로 사용하지 않는다.

## 시장 범위와 숫자 해석

IAB의 2025-11-20 발표는 미국의 의도적인 크리에이터 광고비를 2025년 370억 달러로 **전망**한다(S02). 광고 외 구독·후원·상품 판매까지 포함하는 전체 크리에이터 경제 규모와 다르다. 미국 전망치를 한국 시장 규모 또는 현재 확정 실적으로 전용하지 않는다.

국내 ‘2025년 디지털크리에이터 미디어산업 실태조사’ 공식 파일 검색 결과를 찾았으나 원문 다운로드가 오류 페이지로 연결되었다. 따라서 최신 국내 규모 숫자는 채택하지 않았다. 국내 규모 수치를 넣지 않아도 이 과제의 추천 정책 결정에는 지장이 없으므로 추가 탐색을 중단했다. 국내 비교는 확인 가능한 서비스와 업무 범위 중심으로 작성했다.

IAB 2026 측정 자료는 산업 대화·관찰의 종합이며 독립적인 인과 실험이 아니다(S03). 플랫폼별 지표와 사업 성과의 차이를 설명하는 근거로 활용하며, 정규화 방식의 효과나 가중치의 최적성을 입증하는 자료로 사용하지 않는다.

## 반대 근거와 설계의 한계

- 같은 규모·플랫폼으로 비교해도 카테고리, 게시물 형식·기간 차이가 남는다. 표본을 카테고리까지 쪼개면 너무 작아지므로 포함하지 않고 한계로 명시한다.
- 상대 순위는 절대 조회수 차이를 압축한다. 원지표와 조회수 정렬을 함께 제공해 판단을 보완한다.
- 가격이 알려진 후보만 적격으로 표시하면 신규 후보 기회가 줄 수 있다. 신규 후보를 숨기지 않고 별도 영역에 노출한다.
- 평점은 응답 수·시기·기준을 모른다. 유효 평점은 관측값으로 쓰되 통계적 확신을 만들지 않는다.
- 집행 건수는 성과·신뢰를 입증하지 않는다. 경험 지표로 체감 가산하고 사용자가 선택한 우선순위에 따라 비중을 달리한다. 현재 비중은 제품 가정이며 리서치가 입증한 최적값이 아니다.
- 데이터만으로 선정 문제 전체를 해결할 수 없다. 견적·콘텐츠·오디언스·안전 확인은 후속 업무다.
