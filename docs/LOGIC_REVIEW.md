# 추천 설계 추가 진단

2026-09-21. 기존 추천 정책을 바꾸지 않고 수행한 진단이다. `node --import tsx scripts/review-logic.ts`로 재현한다. 원본 CSV를 읽으며 수정하지 않는다. 현재 정책을 채택할 근거와 반대 사례를 함께 찾는다.

## 표본과 해석

150개 단일 분야×규모×예산 조건 중 적격 후보가 3명 이상인 47조건을 분석했다. 후보 집합은 27개로 중복이 있다. 이는 독립적인 사용자·캠페인 표본이 아니며, 평균 결과는 합성 조건을 같은 비중으로 집계한 값이다. 순위 변화는 추천 품질 개선을 뜻하지 않는다.

## 모든 우선순위의 민감도

각 비중을 하나씩 0.8배/1.2배로 바꾼 뒤 합을 1로 재조정했다. 각 기준별 47×8=376회. 20%포인트 변화가 아니다.

| 기준 | 1위 변경 | 상위 3명 평균 겹침 | 해당 원지표 단순 정렬과 1위 차이 |
|---|---:|---:|---:|
| 콘텐츠 반응 | 20/376 | 96.9% | 29/47 |
| 조회 규모 | 23/376 | 98.0% | 22/47 |
| 협업 이력 | 17/376 | 96.6% | 33/47 |
| 균등 비교 | 26/376 | 96.4% | 비교 안 함 |

단순 정렬은 반응=참여율순, 조회=평균 조회수순, 이력=집행 건수순이다. 이력 단순 정렬은 평점을 고려하지 않는 비교 기준이므로 추천의 정답으로 간주하지 않는다.

## 지표를 하나씩 제거하면

나머지 가중치 합을 1로 재조정했을 때 1위가 바뀐 조건 수. 영향 측정이며 해당 지표가 유용하다는 성과 증거는 아니다.

| 기준 | 참여율 제외 | 조회수 제외 | 평점 제외 | 경험 제외 |
|---|---:|---:|---:|---:|
| 콘텐츠 반응 | 37/47 | 30/47 | 8/47 | 13/47 |
| 조회 규모 | 23/47 | 37/47 | 7/47 | 9/47 |
| 협업 이력 | 17/47 | 18/47 | 20/47 | 13/47 |
| 균등 비교 | 24/47 | 26/47 | 14/47 | 17/47 |

## 설명의 정확성과 유용성을 구분

균등 기준 1위의 최대 기여 지표와 2위 대비 최대 점수 차이를 만든 지표가 29/47조건에서 다르다. 현재 UI는 최대 기여 지표를 보여준다. 계산 오류는 아니지만 “왜 다른 후보보다 앞서는가”에 충분히 답하지 못할 수 있다.

- 뷰티 / micro / 1,000,000원: 민준브이로그180 vs 소라TV177. 1위의 최대 기여는 집행 경험(24.51점), 2위와의 최대 차이는 평균 조회수(+11.23점).
- 뷰티 / micro / 2,000,000원: 민준브이로그180 vs 시우매거진155. 1위의 최대 기여는 집행 경험(24.51점), 2위와의 최대 차이는 참여율(+12.07점).

## 조회 우선의 의미

현재 조회 규모 프리셋의 1위는 22/47조건에서 절대 조회수 1위와 다르다. 다른 3지표와 플랫폼별 상대 위치가 함께 반영되기 때문이다. “예상 도달 최대화”로 설명하면 맞지 않는다.

- 뷰티 / micro / 1,000,000원: 추천 1위 민준브이로그180 8,279회, 최대 조회 후보 지수뷰티151 10,012회.
- 식품 / micro / 1,000,000원: 추천 1위 다은TV16 11,705회, 최대 조회 후보 수아채널107 19,637회.

## 같은 비중이 같은 순위 영향은 아님

유이력 173명의 환산 지표 범위와 모집단 표준편차. 분포가 좁은 지표는 같은 가중치라도 순위 차이를 만드는 폭이 달라진다. 보이는 총점 기여와 후보 간 변별력을 혼동하지 않는다.

## 후속 판단

- 가중치 숫자를 최적값처럼 방어하지 않고 단순 기준·기각 이유·민감한 사례를 문서화한다.
- 순위를 뒤집은 실제 차이와 해당 후보의 주의할 점을 함께 보여주는 설명을 검토한다. “미세 차이”를 통계적 신뢰도처럼 표현하지 않는다.
- 비교 집단·측정 기간 부재·목표와 대리 지표의 차이를 드러낸다.
- 이번 분석은 제품 변경이나 새 프리셋 채택을 의미하지 않는다. 실제 사용자·광고 성과 검증은 남아 있다.

## 소스 대조에서 발견한 설명 오류 — 수정 전

1. 상세 화면은 비교 집단을 플랫폼 전체로 확대했을 때도 중간값을 원래 플랫폼×규모 집단에서 따로 계산한다. 합성 20명에서 계산 집단은 유튜브 전체 20명이고 조회 중간값은 8,500회지만, 현재 상세 수식을 대조하면 나노 2명의 150회를 사용한다. 현재 CSV의 6개 집단은 모두 10명 이상이라 이 분기는 발생하지 않는다. 브라우저 재현이 아닌 소스 검토와 합성 계산 재현이다.
2. 데이터 자세히 보기의 “누적액은 평균 비용×집행 건수와 일치하지 않는다”는 문장이 모든 후보에게 공통으로 노출된다. 이력 없는 27명은 0=0으로 일치하므로 개별 후보 기준으로 문장을 분기해야 한다. 원본 데이터로 동일성을 확인했고 노출은 소스로 확인했다.
3. 평점 결측의 50은 1~5 척도의 가운데인 3.0점에 해당한다. 현재 관측 평점의 환산 범위는 60~100이다. “중립”이 불이익 없음을 뜻하지 않도록 계산 대체값이라고 써야 한다. 실제 결측 27명은 비용 미확인 영역에 있어 점수를 노출하지 않으며, 현재 추천 순위에는 영향을 주지 않는다.

추가 검토에서 발견한 항목이므로 기존 54개 테스트 통과만으로 전체 설명 일치를 보장하지 않는다. 점수 계산에서 비교 집단·중간값을 함께 반환해 UI와 공유하는 수정과 해당 예외 검증이 필요하다. 이 보고서는 수정 완료를 주장하지 않는다.
