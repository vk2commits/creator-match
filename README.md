# Creator Match

**내 캠페인 기준으로 후보를 찾고, 선택 이유를 비교하는 크리에이터 탐색 프로토타입.**

추천 기준 선택 → 분야·예산·팔로워 조건 → 후보 탐색 → 최대 3명 비교 → 검토 메모로 이어진다. 제공된 더미 크리에이터 200명을 브라우저에서 처리하며 외부 API 키·계정·서버 DB 없이 실행한다.

## 3분 안에 살펴보기

1. 아래 명령으로 실행한다.
2. 첫 화면에서 **콘텐츠 반응**을 선택한다. 뷰티·패션, 1만–10만 미만, 2,000,000원을 적용한다.
3. **서연리뷰66**을 담고, 결과 위에서 **조회 규모**로 전환한다. 먼저 나오는 **정은매거진77**을 담아 비교한다.
4. 참여율 8.1% 대 6.5%, 평균 조회수 10,003회 대 35,172회처럼 상충하는 지표를 살핀다. “정답 후보”보다 캠페인에서 우선할 기준을 드러낸다.
5. **비용 미확인** 탭의 3명은 무료 후보가 아니다. 조건을 1원으로 바꾸면 빈 결과와 540,000원으로 1명을 찾는 대안을 확인할 수 있다.

첫 설정을 빠르게 건너뛰려면 **균등 기준으로 예시 보기**를 선택한다. 이후 조건과 담은 후보는 이 브라우저에 저장된다.

## 실행

Node.js **22.12 이상**, npm이 필요하다. 검증 환경은 macOS / Node 25.5.0 / npm 11.8.0이다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 연다. 기본 주소는 `http://127.0.0.1:5173/`다. `index.html`을 파일로 직접 열면 앱이 실행되지 않는다.

```sh
npm test              # 정책·데이터·저장·로딩 테스트
npm run analyze       # 데이터 감사·추천 비교 문서 재생성
npm run build         # 타입 확인 + dist 생성
npm run preview       # 생성한 dist를 로컬에서 확인
```

별도 폴더에서의 의존성 설치·테스트·빌드 재현과 실제 브라우저 검증 범위는 [QA](docs/QA.md)에 기록한다.

## 세 가지 핵심 판단

**조건과 우선순위를 분리했다.** 예산·분야·팔로워는 반드시 충족할 조건이고, 참여율·조회수·평점·이력은 그 안에서 비교할 기준이다. 콘텐츠 반응, 조회 규모, 협업 이력, 균등 비교 중 사용자가 선택한다. 가중치는 설계 가정이며 성과를 학습한 최적값이 아니다.

**모르는 정보를 가격 0원·평점 0점으로 바꾸지 않았다.** 집행 이력 없는 27명은 비용 미확인으로 분리한다. 평균 비용은 과거 참고값이며 현재 견적이 아니다. 평점 공란은 미평가다.

**계산을 읽히기보다 선택을 돕는다.** 목록에는 원지표, 상세에는 추천 이유·추가 확인 사항, 필요할 때 펼칠 수 있는 계산 근거를 둔다. 후보 비교와 검토 메모는 다음 판단으로 연결된다. 첫 UI의 문제와 지원자의 실제 피드백은 [UX 검토](docs/UX_REVIEW.md) 및 [AI 활용 기록](AI_USAGE.md)에 남겼다.

```text

src/experience.ts       저장 복구·금액 표시·비교 메모
src/App.tsx             첫 설정·탐색·상세·비교
src/loadData.ts         데이터 요청·오류 처리
```

## 알고 있는 한계와 트레이드오프

- 제공 데이터에는 채널 URL·사진·실제 전환·타깃 오디언스·관측 기간이 없다. 더미 인물의 링크와 광고 성과를 발명하지 않는다.
- 동일 플랫폼×규모 상대 위치로 비교하되 형식·카테고리·측정 정의 차이는 남는다. 원지표와 정렬을 같이 제공한다.
- 유이력 173명의 평균 비용×건수와 누적액이 일치하지 않는다. 원본은 유지하고 제공 평균으로만 예산을 판정한다.
- 집행 건수는 평점 응답 수가 아니다. 평점 표본이 없는 상황에서 정교한 통계 보정을 가장하지 않는다.
- 점수의 안정성·정책 준수는 검증했지만 실제 추천 정확도·매출 개선·사용자 시간 절감은 검증하지 않았다.
- 인증·실제 문의·계약·다수 크리에이터 총예산 최적화는 제외했다. 첫 설정은 가입 직후를 가정한 데모다.
- 메모는 화면 확인·복사가 가능하다. 파일 다운로드의 저장 동작은 브라우저에 따라 추가 확인이 필요하다.
- 후속 검토에서 집단 확대 시 중간값 설명, 신규 후보의 예산 산술 설명에 불일치를 발견했다. 아직 수정 전이며 구체적인 재현 범위는 [QA](docs/QA.md)에 남겼다.
- 로컬 미리보기는 공개 배포 주소가 아니다. 원격 저장소 공개 상태와 제출 여부는 [추적표](docs/REQUIREMENTS.md)에서 분리한다.
